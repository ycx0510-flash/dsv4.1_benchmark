# BW750 带宽 × 4T 拐点 × DeepInfer/ds41 量化验证

生成时间：2026-11-05  
数据：ds41 750 case（1T/1.6T/2T 全有效；4T 有效 721；DeepInfer 可配对 683）。  
本次只做数据分析，没有占卡。

## 0. 结论摘要

用户的三个主规律，经数据核对后成立，但边界需要量化修正：

1. **短 context**：1.6T→4T 基本没有收益；短 L 的 1T→1.6T 在 `pdt<=2K` 约 -0.9%，`pdt>2K` 约 -10.8%。
2. **长 context**：1T→1.6T 的 2K 阈值不是全局硬阈值。96–512K 的 2–4K 只有约 -2.2%，到 >4K 才约 -9.6%；1M 的 `pdt<=2K` 已有 -5.5% 的长 L 效应。
3. **4T 台阶**：长 L + 小 pdt 确实有断崖。96–512K 的 `pdt<=2K` 1.6T→4T 中位约 **-43.3%**，2–4K 约 **-34.9%**，4–8K 约 **-6.5%**，>8K 基本消失。台阶阈值约 **4K**，不是统一的 2K。
4. **4T 半时延**：只有 CP1 的中位 4T/1.6T 约 **0.486（不到一半）**；CP2/4 约 **0.550/0.564**，约 45% 降幅，不是普遍“一半以下”。
5. **DeepInfer 规律**：CP2 的 >512K 反转最清楚；CP4 只在极小 pdt 窗口（约 ≤512）出现 DI 更高，之后 DI 反而更快；CP4 1M 的 ds41 4T 本身有明显异常。

---

## 1. 口径

- `pdt`：ds41 每 die 的 query/replay token 数，包含 replay 尾；不是简单 `(1-hit)*L`。
- 1T/1.6T/2T：`ms_1024/ms_1636/ms_2048`，no-prof forward timing。
- 4T*：ds41 `HcPre window / n_hcpre`，不是 no-prof 端到端口径。
- DI：DeepInfer `forward_p50_ms`；只取 ds41 4T 有效且 DI `status=OK` 的配对。
- `Q验证_*` 表中的 `median_ms` 都是逐 case 配对 `b-a` 的中位，不是两条边际中位数之差。

## 2. 1T→1.6T：2K 阈值量化

按 `pdt<=2048` / `>2048` 拆开（负值 = 更快）：

| L | n(≤2K) | 1T→1.6T p50（p25~p75） | Δms | n(>2K) | 1T→1.6T p50（p25~p75） | Δms |
| ---: | ---: | --- | ---: | ---: | --- | ---: |
| ≤16K | 91 | **-0.9%**（-9.5~+4.1） | -1.3 | 32 | **-10.8%**（-11.5~-9.7） | -23.4 |
| 20–64K | 167 | **-1.3%**（-3.7~+1.0） | -1.9 | 107 | **-10.2%**（-11.2~-9.0） | -31.4 |
| 96–512K | 166 | **-1.5%**（-2.6~-0.3） | -3.8 | 138 | **-9.2%**（-10.2~-4.3） | -46.6 |
| 1M | 11 | -5.5%（-5.9~-4.8） | -15.8 | 38 | -8.5%（-9.3~-4.9） | -43.8 |
| **ALL** | 435 | **-1.4%**（-3.2~+0.1） | **-2.9** | 315 | **-9.6%**（-10.6~-6.8） | **-35.1** |

分策略：

| 策略 | Q≤2K | Q>2K |
| --- | ---: | ---: |
| CP1 | +1.1%（n=151） | -9.3%（n=135） |
| CP2 | -4.4%（n=149） | -9.9%（n=103） |
| CP4 | -1.5%（n=135） | -9.6%（n=77） |

结论：

- 全部 case：`pdt<=2K` 只有 **-1.4% / -2.9ms**，`pdt>2K` 是 **-9.6% / -35.1ms**；百分比约 7 倍、绝对收益约 12 倍。
- **短/中 L** 的 2K 拐点成立；**96–512K** 的 2–4K 还只有 -2.2%，实际明显拐点在 **>4K**；**1M** 的小 Q 已有 -5.5%，说明长 L 本身会增强带宽敏感性。
- CP1 在 Q≤2K 是 +1.1%（1.6T 反而略慢），CP2 在 Q≤2K 已有 -4.4%，策略拐点不同。

## 3. 1.6T→4T：短 L 无台阶，长 L + 小 Q 有断崖

`1.6T→4T*` 中位（括号为 p25~p75）：

| L | Q≤2K | Q2–4K | Q4–8K | Q>8K |
| --- | ---: | ---: | ---: | ---: |
| ≤16K | **+4.6%**（-0.4~+8.1） | -3.2%（-7.0~+4.0） | -3.6%（-6.5~-2.1） | ≈0 |
| 20–64K | **+0.4%**（-9.2~+5.6） | -1.6%（-6.3~+5.1） | -4.6%（-6.6~-1.6） | ≈0 |
| 96–512K | **-43.3%**（-48.0~-4.2） | **-34.9%**（-43.4~-2.8） | -6.5% | -2.2%（-6.3~+0.1） |
| 1M（ALL） | +5.7%（-44.0~+6.3） | +1.7%（-36.2~+11.1） | -4.2% | -1.0%（-4.2~+3.2） |

注意最后一行：**1M 的 ALL 聚合值被 CP4 拉平**，不能据此说 1M 没有 4T 台阶。分策略后：

- CP1/CP2 在 1M、`pdt<=2K` 仍有 4T 台阶；
- CP4 在 1M 只有 `pdt<=512` 有台阶；
- 因此 1M 的阈值由 CP1/CP2 的约 **2K** 到 CP4 的约 **512**，差异很大。

在 96–512K 内继续细分：

| pdt | n | 1.6T→4T 中位 | p25~p75 |
| ---: | ---: | ---: | ---: |
| ≤512 | 55 | -46.0% | -48.5~-37.3 |
| 513–1024 | 44 | -44.0% | -48.6~-40.6 |
| 1025–2048 | 39 | -45.1% | -53.4~-42.2 |
| 2049–4096 | 31 | -40.4% | -44.4~-4.3 |
| 4097–8192 | 24 | -6.5% | -14.3~-6.3 |
| 8193–16384 | 21 | -1.8% | -5.6~-0.6 |
| 16385–65536 | 27 | +0.1% | -1.8~+1.1 |

**所以长 L 的 4T 拐点在 96–512K 约 4K；超过 4K 后 4T 收益迅速崩到 -6.5%，超过 8K 基本没有收益。**

## 4. 4T 台阶的策略边界

台阶定义：`2T→4T <= -30%`，共 **183/721（25.4%）**。

| 策略 | 台阶 n | L 范围 | pdt p10/p50/p90 | 长 L+小Q 1.6T→4T | 4T/1.6T 中位 | ≤0.5 占比 |
| --- | ---: | --- | --- | ---: | ---: | ---: |
| CP1 | 37 | 65K–1M，中位 131K | 704 / 1189 / 2892 | **-51.4%**（n=39） | **0.486** | 53.8% |
| CP2 | 84 | 32K–1M，中位 115K | 225 / 594 / 2305 | **-45.0%**（n=52） | 0.550 | 1.9% |
| CP4 | 62 | 41K–1M，中位 115K | 178 / 480 / 1469 | **-43.6%**（n=58） | 0.564 | 3.4% |

边界：

- **CP2 最早、最宽**：20K/Q≤512 有局部早台阶；96K 后 Q≤2048；256K/512K 可到 Q≤4096；1M Q≤2048。
- **CP1 居中**：96K 约 Q=1025–4096；256K/512K Q=513–4096；1M Q=1025–2048。
- **CP4 最窄**：96K Q≤1024；256K Q≤2048；512K Q≤1024；1M 只有 Q≤512。

“4T 只有一半”：CP1 的中位确实 0.486（不到一半）；CP2/4 中位约 0.55，只有少数 case ≤0.5。整体台阶样本约 16% 的 case ≤0.5。

## 5. DeepInfer vs ds41 4T 的量化

配对 683 个：CP1 260、CP2 227、CP4 196。正值 = DI 更慢。

### 5.1 分 L 组 × 2K

| 策略 | L 组 | Q≤2K | Q>2K |
| --- | --- | ---: | ---: |
| CP1 | <512K | **+7.5%**（n=147） | +2.5%（n=88） |
| CP1 | 512K | +28.0%（n=3） | -0.1%（n=11） |
| CP1 | >512K | **+49.7%**（n=1） | **-3.4%**（n=10） |
| CP2 | <512K | **-12.2%**（n=139） | -5.3%（n=62） |
| CP2 | 512K | +2.0%（n=7） | -1.1%（n=7） |
| CP2 | >512K | **+16.5%**（n=3） | **-9.7%**（n=9） |
| CP4 | <512K | **-12.1%**（n=118） | -6.2%（n=51） |
| CP4 | 512K | +4.7%（n=10） | -8.9%（n=5） |
| CP4 | >512K | **-36.8%**（n=7） | -27.1%（n=5） |

解释：

- **CP1**：全量中位 **+4.2%**，81% 的 case DI 更慢；长 L 小 Q 可到 **+28%～+50%**，长 L Q>2K 约 **-3.4%**。所以“稍高或持平”大体成立，但不是所有区间。
- **CP2/4 <512K**：小 pdt DI 低约 12%，但优势不是随 pdt 单调变差：CP2/4 在 2–4K 最大（-19%/-17%），4–8K 缩小，约 **8K** 才翻正（+4.7%/+2.1%）。所以“随着 pdt 变大 DI 更大”只在 >8K 成立。
- **CP2 >512K**：小 pdt ≤2K 是 **+16.5%**（DI 慢），>2K 是 **-9.7%**（DI 快），交叉点约 **2K**，你的规律成立。
- **CP4 >512K**：只有 **pdt≤512** 的一个点 DI +24.1%；从 513–1024 起 DI 已经是 **-33.5%**，1025–2048 是 **-37.7%**。所以 CP4 的“小 pdt”门槛大约 **512**，不能和 CP2 的 2K 合并。
- 512K 是过渡区：CP2/4 的小 pdt DI 已经偏高，但样本只有 10/15 个，不能当稳定规律。
- >512K 的 CP2/CP4 只有 12 个/对，>512K 的 CP4 甚至只有 12 个；这些是方向性结论。

### 5.2 CP2/CP4 在 <512K 的 pdt 细节

| pdt | CP2 n / 中位 | CP4 n / 中位 |
| --- | ---: | ---: |
| ≤512 | 76 / **-13.1%** | 66 / **-11.7%** |
| 513–1024 | 33 / -8.6% | 30 / -10.3% |
| 1025–2048 | 30 / -13.2% | 22 / -17.1% |
| 2049–4096 | 22 / **-19.0%** | 20 / **-17.0%** |
| 4097–8192 | 20 / -4.3% | 19 / -5.1% |
| 8193–16384 | 19 / **+4.7%** | 12 / **+2.1%** |

这张表说明：**DI 的优势峰值在 pdt 2–4K，而不是单调递减；约 8K 才翻正。**

### 5.3 CP4 >512K 的例外

| pdt | n | DI vs ds41 |
| ---: | ---: | ---: |
| ≤512 | 1 | **+24.1%** |
| 513–1024 | 2 | **-33.5%** |
| 1025–2048 | 4 | **-37.7%** |
| 2049–4096 | 3 | **-30.7%** |
| 4097–8192 | 2 | -6.8% |

CP4 1M 的 ds41 4T 在 pdt>512 时约 **309ms**，而 CP1 约 118ms、CP2 约 167ms；这是 ds41 CP4 4T 数据明显偏高，不是 DI 在 CP4 上突然变强。只有 pdt≤512 的那一个点符合“DI 更高”。

## 6. 原因分析

### 6.1 1T→1.6T 的 2K 拐点

- `pdt<=2K` 时固定开销、调度、启动成本占比高，1T→1.6T 中位只有 **-1.4% / -2.9ms**。
- `pdt>2K` 后计算量足够大，1.6T 才表现为 **-9.6% / -35.1ms**。
- 96–512K 的 2–4K 只有 -2.2%，说明长 L 下计算量阈值会右移到约 **4K**；1M 的 ≤2K 已 -5.5%，说明长 L 本身会增加 KV 敏感性。

### 6.2 4T 台阶：大 KV + 小 Q 的资源阈值

台阶样本相对非台阶样本：

- `H = L - R_global` 中位：**113,860 vs 38,772**
- `R_global` 中位：**1,288 vs 3,416**
- `pdt` 中位：**690 vs 1,673**

台阶区是“大 KV 缓存 + 小 query”，KV 扫描占主导。4T 可能刚好跨过内存/路径阈值，因此 1T/1.6T/2T 基本平、4T 大幅下降。短 L 时 KV 工作集不够大，没有台阶；pdt 变大后 compute/R 占主导，台阶消失。

这不是 HcPre 段数归一化造成的：台阶内外的 `segments_per_forward` 都是 **80**。

### 6.3 策略差异

CP2 的 Q 窗口最宽、起始 L 最早；CP1 居中；CP4 最窄。合理方向是 CP 切分后的每 die KV 工作集、通信/同步和 attention 分块不同；现有列还不足以严格区分 HBM 带宽和 HcPre kernel 路径，需要 kernel counters。

### 6.4 DeepInfer 差异

DI 在小平 pdt 时实际工作量更小。用 `new_tokens_per_request / cp` 近似 DI 每 die token，相对于 ds41 pdt：

| pdt | CP1 | CP2 | CP4 |
| --- | ---: | ---: | ---: |
| ≤512 | **0.821** | 0.928 | 0.936 |
| 513–1024 | 0.931 | 0.944 | 0.974 |
| 1025–2048 | 0.936 | 0.973 | 0.980 |
| >4096 | ≈0.98 | ≈0.99 | ≈0.99 |

因此：

- 小 pdt 的“DI 更低”有 6%–18% 是工作量/几何差异，不全是 kernel 效率。
- CP1 即使少做约 18% 的 token，仍然比 ds41 慢 7.5%（全量中位 +4.2%），长 L 小 Q 到 +28%～+50%，说明 CP1 长上下文路径有额外开销。
- >512K 的 CP2 反转与 4T 台阶一致：小 pdt 时 ds41 4T 台阶生效（约 167ms），DI 约 195ms；pdt>2K 后 ds41 台阶消失（约 325ms），DI 约 261ms。
- CP4 1M 的 ds41 4T 在 pdt>512 约 309ms，是异常高值，导致 DI 看起来更快；只有 pdt≤512 的 1 个点符合“DI 更高”。
